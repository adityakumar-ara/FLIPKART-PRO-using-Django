# Flipkart Pro - Color Palette Guide

## Primary Colors
- **Primary Blue**: `#0d6efd` - Main action color, buttons, links, hover states
- **Secondary (Dark Slate)**: `#1e293b` - Secondary buttons, dark elements
- **Dark**: `#020617` - Very dark backgrounds, text on light backgrounds

## Semantic Colors
- **Success (Green)**: `#10b981` - Positive actions, completed states
- **Info (Light Blue)**: `#3b82f6` - Information, alerts, notifications
- **Warning (Yellow)**: `#f8b619` - Warnings, important notices
- **Danger (Red)**: `#dc3545` - Errors, delete actions, critical alerts

## Neutral Colors
- **Light (White)**: `#ffffff` - Backgrounds, cards, light surfaces
- **Body Text**: `#0f172a` - Primary text color
- **Secondary Text**: `#334155` - Navigation, secondary text
- **Background Gradient**: `linear-gradient(180deg, #f8fbff 0%, #eef4ff 100%)` - Page background

## Usage Guidelines
1. **Buttons**: Use `#0d6efd` for primary actions, `#1e293b` for secondary
2. **Links**: Use `#0d6efd` with hover effect
3. **Alerts**: Use semantic colors (success, warning, danger, info)
4. **Backgrounds**: Use white `#ffffff` for cards, gradient for page background
5. **Text**: Use `#0f172a` for main text, `#334155` for secondary
6. **Borders**: Use `rgba(13, 110, 253, 0.35)` for subtle primary borders

## Button Styles
- **Primary Button**: Gradient background `linear-gradient(135deg, #2563eb 0%, #0d6efd 100%)` with shadow
- **Outline Primary**: Transparent with `#0d6efd` border and text
- **Hover States**: Add slight background color change or opacity adjustment
